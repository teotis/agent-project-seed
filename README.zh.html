Agent Project Seed

极简的项目种子，clone 即用，可以方便地按你自己的习惯进行后续开发。

  • Python >= 3.9，零运行时依赖
  • 支持 Codex / Claude Code

已搭建的功能

功能说明
状态面板展示项目状态、git 状态、账本记录数、目标和下一步
安全提交基于白名单的提交命令，适用于 Agent 产出的改动
统一账本请求、决策、会话、风险、问题和产物共用一种结构化记录格式
健康检查验证必需文件、入口文件同步、hooks、gitkeep、包导入和平台垃圾文件
Agent 同步从共享规则重新生成 CLAUDE.md
工具包Python 辅助模块：路径管理、原子写入、环境变量加载、API 门控、Record/Ledger/Manifest/QC、Review 页面
多 Agent 入口各工具专属文件统一指向同一份共享合约
