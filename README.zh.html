Agent Project Seed v1.0

复制即用的多 Agent 协作项目底座。Clone 后打开 AI 编程工具，面板自动引导初始化——无需手动配置。

  • Python >= 3.9，零外部依赖
  • 支持 Codex / Claude Code / Gemini CLI

适合什么

  • 用 AI Agent 辅助开发，需要统一工程纪律
  • 多 Agent 协作的代码库
  • 需要结构化记录需求、决策、风险的轻量项目

已搭建的功能

功能说明
状态面板每次 Claude Code 对话自动注入。三档：Seed Template → Initialized, goals pending → Ready
安全提交基于白名单的 commit 命令，自动拒绝 .env、work/tmp/、work/out/ 及白名单外文件
统一账本需求、决策、风险、产物统一以 Record 结构化记录到 control/ledger.md
健康检查project.py check 验证文件、同步、面板、hook、gitkeep、平台垃圾文件
Agent 同步project.py sync-agents 从 control/contract.md 重新生成 AGENTS.md、CLAUDE.md、GEMINI.md
Python 工具包src/base_scaffold/ — 路径管理、原子写入、环境变量加载、API 门控、Record/Ledger/Manifest/QC、HTML Review
多 Agent 入口平台专属入口文件（AGENTS.md、CLAUDE.md、GEMINI.md）均指向共享规则源
自动存档Stop hook 在每次对话结束时自动执行安全提交

目录说明

├── contract.md # 唯一共享规则源
├── ledger.md # 统一记录账本
└── state.md # 当前态快照
work/ # 工作层
├── in/ # 输入材料
├── out/ # 正式产物（不提交）
└── tmp/ # 临时文件（不提交）
tools/
├── project.py # 初始化、预检、同步、安全提交
└── panel.py # 面板生成器
src/
└── base_scaffold/ # Python 工具包
tests/ # 测试
.claude/
├── hooks/panel_hook.py # 面板注入 hook
└── settings.example.json
AGENTS.md # Codex 入口
CLAUDE.md # Claude Code 入口
GEMINI.md # Gemini CLI 入口
