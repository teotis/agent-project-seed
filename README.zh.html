Agent Project Seed

极简的项目种子，clone 即用，可以方便地按你自己的习惯进行后续开发。

  • Python >= 3.9，零运行时依赖
  • 支持 Codex / Claude Code

已搭建的功能

功能说明
状态面板中文展示进入/交接快照：优先呈现用户目标、验收进度、证据、缺口与下一决策；随后才是 Git、open 记录和风险
安全提交基于路径白名单和高置信 secret 扫描的提交命令，在 staging 前拒绝敏感内容
Clean Checkpoint只针对当前会话新增的 tracked 改动执行 Stop gate，保留用户已有脏改动并支持明确 blocked handoff
统一账本请求、决策、会话、风险、问题和产物共用一种结构化记录格式
健康检查验证必需文件、入口文件同步、hooks、gitkeep、包导入和平台垃圾文件
Agent 同步从共享规则重新生成 CLAUDE.md
Work Packet仅在跨包、worktree、Agent 或交接会话的复杂任务中启用 curated context、live state 和知识提升复核
Governance Lifecycle面向长期项目的可选规则生命周期评审面，不会默认增加 hook 或强制流程
Portable User Skills仓库本地保留 38 个 Skill 快照；默认推荐小型工程核心，专家能力显式启用
工具包Python 辅助模块：路径管理、原子写入、环境变量加载、API 门控、Record/Ledger/Manifest/QC、Review 页面
多 Agent 入口各工具专属文件统一指向同一份共享合约
